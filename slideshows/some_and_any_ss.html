01 · Affirmative Sentences

Some

We use SOME in affirmative sentences and when we want to offer or ask for something.

Primary Use
Some → affirmative sentences
Use some when making a positive statement about an unspecified quantity — whether countable or uncountable.
Also used in offers and requests even if the sentence has question form — see Topic 02 for details.
  • 01"There are some new people in my English class."
  • 02"I bought some new shoes."
  • 03"There is some milk in the fridge."
  • 04"I took some money out of the bank."
  • 05"Peter has bought some new books."
  • 06"She always takes some sugar with her coffee."
  • 07"Here is some food for the cat."
  • 08"I have some magazines for you."

02 · Special Uses of Some

Some — Offers & Requests

Even in question form, we use some (not any) when offering something or making a polite request.

When offering something, the speaker expects the answer to be yes — that's why some is used, not any.
  • 01"Would you like some wine?"
  • 02"Do you want some soup?"
  • 03"Have some cake… it's delicious!"
  • 04"You look thirsty. Have some water."
  • 05"I've got lots of apples. Do you want some?"
  • 06"If you're hungry, eat some chips."
When asking for something politely, the speaker also expects a positive response.
  • 01"Can I borrow some money?"
  • 02"Could you give me some books to read on vacation?"
  • 03"Can I have some more coffee?"
  • 04"Could you give me some help with this?"
  • 05"Would you please give me some apples?"
Why some and not any in questions?
Any in questions → neutral, no expectation either way.
"Do you have any brothers or sisters?" (genuinely don't know)
Some in questions → signals an expectation of yes.
"Would you like some wine?" (offering — expecting acceptance)

03 · Negatives & Neutral Questions

Any

We use ANY with negative sentences and with neutral questions — neither offers nor requests.

Primary Use
Any → negatives + neutral questions
Negatives: With not, any means none at all.
"There isn't any beer in the fridge." (= there is no beer)
Neutral questions: Genuinely asking — no expectation of yes or no.
"Do you have any children?" (genuine question)
  • 01"There isn't any beer in the fridge."
  • 02"There aren't any good films on TV."
  • 03"I don't have any free time."
  • 04"Jane doesn't have any friends."
  • 05"I don't want any presents for my birthday."
  • 06"There aren't any apples left."
  • 07"There aren't any folders in my bag."
  • 08"Pam does not have any pencils on her desk."
  • 01"Are there any good restaurants near here?"
  • 02"Do you have any children?"
  • 03"Have you got any brothers or sisters?"
  • 04"Have you got any questions?"
  • 05"Did they have any news for you?"
  • 06"Could you check if there are any calls on the answering machine?"
  • 07"Is there any lemonade left?"
  • 08"Have you got any tomatoes?"

04 · Comparison

Some vs Any — Side by Side

Seeing both words contrasted in equivalent sentences makes the choice clearer at a glance.

Some ✓

"Sue went to the cinema with some of her friends." (aff.)

"Here is some food for the cat." (aff.)

"Would you like some wine?" (offer)

"Can I borrow some money?" (request)

Any ✓

"Jane doesn't have any friends." (neg.)

"There isn't any food left." (neg.)

"Are there any restaurants nearby?" (neutral Q)

"Do you have any money on you?" (neutral Q)

  • 01"We need some bananas." — "You can't buy any posters in this shop."
  • 02"I have some magazines for you." — "There aren't any folders in my bag."
  • 03"There are some apples on the table." — "There aren't any apples left."
  • 04"I'll have some sandwiches." — "They didn't sing any songs."
  • 05"I've seen some nice postcards here." — "Pam doesn't have any pencils."

05 · Quick Reference

Summary Table & Golden Rule

One table, one rule — everything you need to choose correctly every time.

Sentence TypeSomeAny
Affirmative statement✓ Always✗
Negative statement✗✓ Always
Offer (question form)✓ expect yes✗
Polite request (question form)✓ expect yes✗
Neutral question (no expectation)✗✓ Always
The Golden Rule:
If you expect the answer to be "yes" → use Some.
If the answer could be yes or no (neutral) or you are denying → use Any.
